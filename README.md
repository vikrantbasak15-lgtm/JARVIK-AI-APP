## ✅ Installation

### Step 1: Download the app
Go to the repository files and download the executable named:

`JARVIK-AI.exe`

### Step 2: Run the installer
1. Double-click the downloaded file
2. If Windows asks for confirmation, click **More info** and then **Run anyway**
3. Follow the installation steps shown by the setup wizard
4. Choose the installation folder and complete the installation

### Step 3: Launch JARVIK
Once installed, open the app from:
- Desktop shortcut
- Start menu
- Installed program folder
